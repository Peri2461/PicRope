# PicRope · 图绳

把截图挂在屏幕上沿，复制、拖拽和保存时随手取用。英文名为 `PicRope`，中文名为「图绳」。应用、窗口与托盘统一使用奶白底、麻绳木夹和蓝色图片卡片图标。

## 启动

从 [v1.0.0 发布页](https://github.com/Renly1994/PicRope/releases/tag/v1.0.0) 下载并解压 `PicRope-1.0.0-windows-x64.zip`，双击 `Install.cmd`。程序安装到当前用户的 `%LOCALAPPDATA%\Programs\PicRope`，桌面创建 `PicRope` 快捷方式。在 Windows「已安装的应用」中可卸载「PicRope · 图绳」，卸载会清理该工具的收集副本、设置和缓存。

双击 `build/PicRope.exe`。程序常驻系统托盘，点击托盘图标或按 `Ctrl+Alt+T` 显示、收起绳子。鼠标停在屏幕最上沿约 0.3 秒也可展开，移开后停留 1.2 秒再自动收起；在这期间移回绳子可继续操作。新增截图或编辑完成后先保持显示 2 秒，再按鼠标移开的等待时间收起。

Windows 10/11，需要 .NET Framework 4.8 和 Microsoft Edge WebView2 Runtime，无需另装 SDK。编辑器使用 WebView2；若系统缺少该运行时，可从 [微软官网](https://developer.microsoft.com/microsoft-edge/webview2/) 安装。

## 收集截图

- `Win+PrtScn` 保存到 Windows 截图文件夹的新图片自动挂上，支持系统截图目录迁移。
- 托盘中的「收集剪贴板截图」开启后，`Win+Shift+S`、`PrtScn`、微信 `Alt+A` 产生的纯图片会保存到独立收集目录并挂上。支持剪贴板的 `PNG`、`image/png`、`Bitmap` 和原生 DIB 位图格式。此选项默认关闭。
- 图片文件支持 PNG、JPG/JPEG、BMP、GIF、TIF/TIFF。
- 带文字、网页内容或文件的剪贴板不会被当作纯图片收集。
- 同一次截图同时进入文件夹与剪贴板时，按图片内容合并通知；同尺寸的不同截图分别保留。
- 可通过托盘「添加图片」手动挂上已有图片。

新截图沿弧线缩小飞向绳子，抵达后轻轻摆动；其他图片弹性让位。绳子展开时柔和回弹，挂着的图片偶尔随风轻摆，取下时向下落走。Windows 未提供截图区域坐标时，飞入起点根据截图尺寸和鼠标位置估算。

滚轮横移时，图片随移动方向产生轻微惯性摆动，停下后逐渐回稳。模拟风吹的间隔在 7～24 秒之间随机变化，每阵风随机从左侧或右侧吹来，图片轻摆后逐渐回稳；滚动期间暂缓风吹。微风由定时器检查，画面静止时仍可触发；收起后保留计时，重新展开不会重置倒计时。

## 操作

| 操作 | 效果 |
| --- | --- |
| 单击图片 | 同时复制图片与文件 |
| 双击 | 用默认图片应用打开 |
| 长按或右键「编辑图片」 | 打开内置 Filerobot 编辑器 |
| 拖拽 | 按目标应用的 Windows 复制、移动规则传递文件；移动完成后自动取下 |
| 单击夹子 | 夹子轻捏松开，照片自动落到下方桌面，由小图钉固定为置顶贴图，保留原文件和展示记录 |
| 拖动桌面贴图 / 滚轮 | 调整贴图位置 / 缩放图片 |
| 单击桌面贴图上沿的图钉 | 拔下图钉，展开绳子，将图片沿弧线挂回 |
| 右键「保存副本」 | 保存到指定位置，保留原图 |
| 左上角叉号 | 收集目录中的图片进回收站；外部图片仅从绳子上取下 |
| 滚轮 | 浏览超出屏幕宽度的图片 |
| 托盘「全部取下」 | 清空绳子，保留所有原文件 |

图片右键菜单和托盘右键菜单使用统一的浅色圆角样式。菜单打开时绳子保持显示，点击菜单外部或按 `Esc` 可关闭。

保存确认、操作提示、工具提示和编辑器错误页面使用同一套浅色样式。未保存时关闭编辑器，可选择「不保存」「继续编辑」或「保存并关闭」；`Esc` 返回编辑。操作提示不会抢走输入焦点。文件选择使用 Windows 原生对话框。

内置编辑器采用浅色中文界面，顶部保留画笔、箭头、文字、形状、裁剪、旋转和样式工具；不透明度等选项按需展开。尺寸调整、调色、滤镜、贴图、翻转和导出操作收在「更多」中。编辑原始分辨率图片，资源随程序提供，图片在本机处理，无需上传。

裁剪、旋转、调整尺寸、调色、滤镜和插入图片都有独立的「返回」「应用」操作栏。「返回」或 `Esc` 取消本次操作，保留此前的编辑；「应用」保留当前效果并返回原来的标注工具。右上角「完成」保存整张图片并关闭编辑器。

进入编辑器后默认选择空心矩形框，标注默认使用红色。选择画笔、箭头或形状工具后，工具下方显示八种固定颜色和细、中、粗三档线条，对已选中的标注和后续绘制均生效。长按打开编辑器时窗口弹到前台，转到其他窗口后解除置顶。

选择文字工具后，在图片上单击即可输入；单击已有文字可继续修改。`Enter` 完成输入，`Shift+Enter` 换行，`Esc` 取消本次输入。输入完成后可拖动文本框的四个角，等比例放大或缩小文本框和文字，支持撤销。直接点击「完成」、保存或复制也会保留输入中的文字。文字工具下方提供八种固定颜色和小、中、大三档字号，统一使用支持中文的微软雅黑。

- 「完成」保存当前图片并关闭编辑器，图片从编辑画布向上缩小飞回绳子，落稳后轻轻回弹并显示最新缩略图。正常关闭编辑器时也会挂回图片。
- 「更多 → 保存」或 `Ctrl+S` 回写当前图片并继续编辑。
- 「另存为」保存新文件并自动挂上，保留原图。
- 「复制图片」复制完整分辨率的编辑结果，不改动原文件，也不会被剪贴板收集重复挂上。
- `Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做；`Ctrl+S` 保存，`Ctrl+Shift+S` 另存，`Ctrl+Shift+C` 复制。关闭未保存的编辑器会提醒保存。

模糊和像素化目前作用于整张图片，不提供局部打码。GIF、TIFF 等多帧图片只编辑第一帧。

保留最近 50 张图片的展示记录，超出数量的旧图片仅取下，文件仍然保留。全屏应用在前台时绳子自动收起。

设置和展示记录位于程序旁的 `data/state.json`，收集图片位于 `data/Captures` 文件夹。运行错误写入 `data/error.log`。移动程序时一并保留 `data` 文件夹。开机启动由托盘选项控制，默认关闭。

## 构建与验证

```powershell
.\build.ps1
.\build.ps1 -DesktopTests
.\build.ps1 -FolderTests
.\build.ps1 -MenuTests
.\build.ps1 -EditorTests
.\build.ps1 -WindTests
.\build.ps1 -Package
```

第一条命令构建应用并运行核心测试；第二条还会运行桌面交互测试；第三条验证资源管理器实际打开收集目录；第四条验证两处右键菜单的显示、复制、开关保存与关闭操作。桌面测试会短暂操作鼠标和剪贴板，结束时恢复，并把测试图片、界面预览与动效预览帧放在 `build` 目录。实际菜单预览位于 `previews/右键菜单/实际菜单.png`。

`-EditorTests` 验证编辑入口、原图分辨率、标注、复制、保存、另存、窗口关闭及文件格式，编辑器预览位于 `previews/图片编辑/内置编辑器.png`。`-Package` 生成 `releases/PicRope-1.0.0-windows-x64.zip`，逐文件打包应用、编辑器、WebView2 SDK、安装卸载脚本与许可声明，并校验完整清单。发布包不包含个人截图、设置、浏览器缓存或测试产物。

`-WindTests` 只验证微风自然触发、静止时唤醒动画、收起后恢复计时、随机间隔与方向，以及滚动时暂停和恢复微风。指定目录、菜单、编辑器、主题或微风专项测试时，只运行相应功能的测试。

`python -X utf8 tests/EditorUiTests.py` 验证简洁工具栏、标注、样式面板、撤销重做、裁剪比例、翻转、尺寸调整和滤镜，需安装 Python 的 Playwright、Pillow 和 Chromium。界面预览位于 `previews/图片编辑/简洁编辑器.png`。
